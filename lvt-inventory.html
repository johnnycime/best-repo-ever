🔗 Connect to Google Sheets

Your inventory will be saved to a Google Sheet you own. Data syncs automatically on every save. You'll need a free Google Cloud API key + OAuth Client ID (one-time setup, ~5 min).

✅
Connected to Google Sheets
  1. Go to Google Cloud Console → create a project → enable Google Sheets API
  2. Go to APIs & Services → Credentials → Create API Key → copy it below
  3. Create an OAuth 2.0 Client ID (type: Web Application). Add your file's URL (or http://localhost for local use) as an Authorised JavaScript Origin
  4. Create a blank Google Sheet. Copy its ID from the URL: …/spreadsheets/d/THIS_PART/edit
  5. Paste all three values below and click Connect & Authorise
